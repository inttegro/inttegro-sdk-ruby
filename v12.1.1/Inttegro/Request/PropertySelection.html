Overview

Public properties to include in or exclude from one named response resource. Supply exactly one of pick or omit.

This generated model is immutable. Construct it with .new, or decode a string-keyed API payload with .from_hash. #serialize produces a string-keyed hash using the original wire field names and serialized enum values.
